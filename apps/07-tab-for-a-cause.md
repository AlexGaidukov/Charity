# Tab for a Cause / Gladly

## Суть / модель
- Новая вкладка браузера с рекламой (Raptive): доход делится между фондами пропорционально Hearts, которые раздают пользователи. Плюс видео за Hearts, поиск и кэшбэк (Shop for a Cause).
- Разбор кода: [07-tab-for-a-cause-decompile.md](07-tab-for-a-cause-decompile.md), лендинг: [07-tab-for-a-cause-landing-nmt.md](07-tab-for-a-cause-landing-nmt.md)

## Платформы и онбординг
- Расширения для Chrome и Edge (10 КБ, только редирект на tab.gladly.io/newtab), Safari (Mac App Store), мобильное «App for a Cause» (iOS/Android, оболочка над v5). Firefox не поддерживается.
- Онбординг: установка → обязательный вход (Google/Apple/email) → выбор каузы → username → верификация email. Затем промо Shop for a Cause, тур из 2 шагов и вкладка v4. Реклама со 2–3-й вкладки. Подробно: [07-tab-for-a-cause-walkthrough.md](07-tab-for-a-cause-walkthrough.md)
